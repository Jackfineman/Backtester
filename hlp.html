Method: Hyperliquid exposes cumulative PnL and account-value series per timeframe bucket. Account value moves with both trading PnL and user deposits/withdrawals, so naive (AV_end − AV_start) / AV_start misstates real performance. For each interval we take Δpnl = pnl[i] − pnl[i-1] (pure trading PnL) and divide by the account value at the start of that interval, giving a clean per-period return. Returns are chain-linked into a NAV index (rebased to 1.0 at the start of the selected window), and CAGR is NAV_end365/days − 1 over the window. This is standard time-weighted return.

Gotchas: the API ships fixed buckets — day/week/month/allTime — so the sample spacing on "allTime" is coarse (~12 days/bar for HLP). Intra-bar drawdowns get smoothed away, which is why perpAllTime can show near-zero drawdown even when the vault clearly dipped. For tighter resolution on a recent window, pick a shorter bucket (e.g. month) and narrow the range.

allTime vs perpAllTime: HLP runs spot market-making plus the perps liquidation backstop. allTime is the full vault; perpAllTime is only the perps portion.
