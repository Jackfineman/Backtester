Hyperliquid Vault CAGR Calculator

Time-weighted return, stripping out deposits/withdrawals.

How this works: Hyperliquid exposes a cumulative PnL series and an account-value series. Account value moves with both trading PnL and user deposits/withdrawals, so naive (end - start) / start over account value overstates or understates real performance. Instead, for each interval we compute the trading PnL delta (pnl[i] - pnl[i-1]) and divide by the account value at the start of that interval to get a clean per-period return. Those returns are chain-linked into a NAV index (starts at 1), and CAGR is NAV_end^(365 / days) - 1. This is the standard time-weighted return method.
